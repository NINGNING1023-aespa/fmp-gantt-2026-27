## 在 MacBook 上打开

- 在线：打开本仓库配置的 GitHub Pages 地址。
- 离线：下载仓库 ZIP 并解压，用 Safari 或 Chrome 打开 index.html。
- 无需安装 Node、Excel 或额外字体，也无需启动服务器。

任务日期与内容沿用 FMP 主计划；进度状态未经核实，不代表实际完成。
